# Ansible Configuration & Node Bootstrapping (Question 4.g)

**Assessment Rubric:** Question 4.g — Server Configuration Management & Kubernetes Bootstrapping (4 Marks)  
**Target Cluster:** 1 Control-Plane + 2 Worker EC2 Nodes (with 10 GB dedicated `gp3` EBS volumes on workers)

## Directory Structure

```text
ansible/
├── ansible.cfg          # Global Ansible engine settings & SSH pipelining
├── inventory/hosts.ini  # Auto-generated by Terraform apply (zero manual IP edits)
├── site.yml             # Master playbook running Phase 1 + Phase 2
├── playbook.yml         # Phase 1: common, containerd, kubernetes, hardening
├── cluster-init.yml     # Phase 2: kubeadm init, Calico CNI, worker join, Ingress, Storage, ArgoCD/Rollouts
├── run-ansible.sh       # Single-command execution harness
└── roles/
    ├── common/          # Swapoff, kernel modules, sysctl, 10GB EBS ext4 mount (/var/lib/shoplite-storage)
    ├── containerd/      # containerd.io + SystemdCgroup=true
    ├── kubernetes/      # kubelet/kubeadm/kubectl v1.30 + AWS ECR credential provider + Helm 3
    └── hardening/       # Question 3 hardening (deploy/ops, setfacl, sshd, systemd backup, UFW)
```

## Single-Command Execution (from Terminal 1 after `terraform apply`)

```bash
./run-ansible.sh check   # Syntax validation
./run-ansible.sh all     # Full bootstrap, cluster init, CNI, Ingress, Storage, ArgoCD & kubeconfig fetch
```
